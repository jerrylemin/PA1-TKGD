# PA1 continuity for PA4

PA1 established the product pair used by the later assignments: FIFA.com as a browse-first official football ecosystem and Chess.com as an action-first play, review, analysis, and learning platform.

## FIFA problem carried forward

Ticket discovery was distributed across tournament cards and related properties rather than presented as one consolidated status view. Ticket planning is trust-sensitive: a user needs to know what is true now, which source is official, and what the next step means. The PA4 Status Dashboard addresses this inherited problem.

## Chess problem carried forward

Chess.com exposes many learning and analysis entry points. Beginners can reach puzzles and lessons, but advanced analysis controls and notation add recall and vocabulary load. A useful learning path needs a visible bridge from mistake explanation to an actionable practice continuation. The PA4 Beginner Review Flow addresses this inherited problem.

## Inherited design principles

- Make the primary user goal visible before secondary features.
- Preserve source and context when a workflow crosses a product boundary.
- Explain unfamiliar terminology in the flow that needs it.
- Connect explanation to a next action that lets the user continue learning.
